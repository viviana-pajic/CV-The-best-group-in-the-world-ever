# Error casebook

Detector cases use the seven reserved same-video frames and approximate reference boxes. At confidence 0.25 and IoU 0.50, an amber box is unmatched and a pink reference is missed. Incomplete references can make a real detection appear unmatched.

| Case | Evidence and likely cause | Change and result |
|---|---|---|
| E01 · Original 4021 (160.84 s), R13 | Missed visible body reference in the tuned result. Supporting hand and foot stretch the visible extent. Nearby boxes overlap the same region. [Comparison](../experiments/error_analysis/frame_4021.jpg) | Visible-extent labeling corrected proposals in training. On the reserved diagnostic both models matched 42/46 visible-contact bodies. Audit long horizontal poses independently. |
| E02 · Original 4061 (162.44 s), R10–R14 | Closely stacked bodies have several missed hidden-contact references and overlapping predictions. [Comparison](../experiments/error_analysis/frame_4061.jpg) | The tuned detector matched 51/68 hidden-contact bodies on development versus 38/68 before. Reserved coverage fell from 34/50 to 30/50. Test overlap suppression and label completeness on a separate set. |
| E03 · Original 4021, P17 | Duplicate false positive against the reserved reference: P17 overlaps R0 by IoU 0.72, but P11 already matched R0. P11 and P17 overlap by 0.51, below the 0.55 merge setting. [Comparison](../experiments/error_analysis/frame_4021.jpg) | The reserved counts were 41 unmatched for the earlier detector and 50 for the 300-image detector at this setting. A lower merge threshold may remove this duplicate and suppress true overlapping bodies. Measure both effects before changing it. |
| E04 · Wicked Games, 10–20 s | Dark costumes and a bright floor reflection obscure floor support. The median frame shows six boxes and one solid contact. [Replay](../dashboard/index.html) | The learned visibility head can withhold a point. Compare with brighter sections and collect independent low-light labels before changing the threshold for evaluation. |
| E05 · Original reserved hidden-contact cases | Box geometry can report a point behind another dancer or when support cannot be seen. | The 300-image joint pipeline reported two of 50 hidden contacts as measured, versus five for the published baseline. That is a contact failure measure, distinct from box AP. |
| E06 · Camera shifts and stage edges | A single image-to-stage map drifts as camera framing changes. Off-screen front corners must be extrapolated in the original calibration. | Align stationary venue landmarks over time. 14 same-image edge picks give a median residual of 0.37 px for the draft, down from 12.34 px for the first map. Independent cross-clip planar landmarks are needed to measure transferred accuracy. |
| E07 · Lost identities | A reappearing person can get a new ID after overlap. Smooth output can still belong to the wrong person. | Compare tracker continuity on identical detections. Collect continuous human ID references for crowded crossings. |
| E08 · Airborne or uncertain support | A jump or unresolvable blur breaks the measured floor-contact assumption. Near-boundary map position can be ambiguous. | Withhold a measured point. The UI draws temporal estimates as hollow. Collect labeled jumps and edge cases before scoring these separately. |

For the defense, open a labeled error example, point to the body or contact, explain how the label was made, and show which comparison supports the proposed fix.

The frozen Wicked Games check also found a large contact error at frame 425. The solid replay dot missed an approximate visual reference by 2.68 m, and the raw contact estimate was already 2.68 m away on the same box. The matched box-bottom position was 0.39 m away. This case points toward the raw contact estimate, with the stage calibration and visual-reference uncertainty shared across the comparison.
